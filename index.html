How the bracket fills itself

1. Group stage. Enter each score and the standings re-sort instantly using FIFA's tiebreakers: points → goal difference → goals scored, then head-to-head (points, GD, goals) between level teams, then fair play / drawing of lots.

2. The "best third-placed teams". 12 groups each send their top 2 (24 teams). The competition needs 32, so the 8 best of the 12 third-placed teams also advance. They're ranked across all groups by points → GD → goals scored. The bottom 4 thirds go home.

3. The tricky part — who plays whom. Which third-placed team each group winner faces depends on which 8 groups produced a qualifying third. FIFA pre-published a lookup table with all 495 possible combinations (Annex C). This app embeds that exact table: once all 12 groups are final, it reads off the official Round-of-32 pairings automatically.

4. Knockout. Enter scores to send winners forward. If a knockout game is level, a penalty picker appears so someone advances. The bracket rebuilds all the way to the Final 🏆.

5. Multiple players. Use the 👤 Profiles bar at the top to create one button per person. Click a name to load and edit that person’s bracket — each keeps its own independent predictions. Export sends the current profile to a file; Import drops someone else’s file back in as a new profile.

6. Run a pool. Mark one profile as ⭐ official results (the ☆ star on its chip) and fill it in as games are played. The 🏆 Leaderboard tab then ranks everyone else against it live — points for correct qualifiers, exact group scores, and how far each team advances. All point values are editable (⚙ in the Leaderboard tab).

7. Lock & reveal. When the first match kicks off, every prediction automatically becomes read-only and all participants' brackets become public — anyone can open a name under 🔓 Everyone's picks to view it. Your ⭐ official-results profile stays editable so you can keep entering real scores.

In a hurry? Every game has its own 🎲 button that rolls a random score (0–3 goals each) for just that match. Or use 🎲 Random all in the toolbar to fill every still-empty game at once. Knockout ties get a random penalty winner so the bracket still completes.

Everything is saved in your browser automatically, per profile.
